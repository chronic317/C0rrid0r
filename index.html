C0RRID0R
Missing Persons Alert System — Indiana

C0RRID0R is a real-time investigative dashboard built to support the search for missing persons across Indiana's highway system.

When an alert is issued, every second matters. C0RRID0R pulls live data from the Indiana State Police and connects it directly to 734 INDOT traffic cameras — so investigators, families, and volunteers can watch the corridors a missing person may be traveling in real time.

The system monitors all four active Indiana alert types:

⬤ AMBER — Missing Children
⬤ SILVER — Missing Seniors
⬤ GREEN — Missing Adults
⬤ BLUE — Missing Law Enforcement

C0RRID0R is intended for use by independent investigators, case researchers, concerned families, and volunteers working missing persons cases in Indiana.

This is not an official law enforcement tool. Always defer to ISP and local authorities during active emergencies.
