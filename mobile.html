C0RRID0R
Missing Persons Alert System — Indiana

C0RRID0R is a real-time investigative dashboard built to support the search for missing persons across Indiana's highway system.

When an alert is issued, every second matters. C0RRID0R connects live Indiana State Police alerts directly to 734 INDOT traffic cameras — so investigators, families, and volunteers can watch the corridors a missing person may be traveling in real time.

The system monitors all four Indiana alert types:

⬤ AMBER — Children
⬤ SILVER — Seniors
⬤ GREEN — Adults
⬤ BLUE — Law Enforcement

Intended for independent investigators, case researchers, concerned families, and volunteers working missing persons cases in Indiana.

Not an official law enforcement tool. Always defer to ISP and local authorities during active emergencies.

Built by Naptown Unsolved — Indianapolis, Indiana
Camera feeds via INDOT / 511in.org. Alert data from Indiana State Police. C0RRID0R does not store personal data. For emergencies, call 911.
